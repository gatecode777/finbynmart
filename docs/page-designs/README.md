# Page design specifications

One file per approved page, named `<id>-<slug>.md`, matching the IDs in `docs/PAGE_TRACKER.md`. Each spec lists: objective, reference image, layout structure, section order, component list, typography, colors, desktop / tablet / mobile design, interactive behaviour, data requirements, loading / empty / error states, accessibility and acceptance criteria. Use `01-homepage.md` as the template.

| ID | Page | Spec | Reference |
|---|---|---|---|

| 02 | All Categories | [02-all-categories.md](02-all-categories.md) | `../design-references/02-all-categories-reference.png` |

A page is Design Complete only when its reference is finalized, its spec exists here, its implementation prompt has been delivered and approved, and the tracker is updated.
