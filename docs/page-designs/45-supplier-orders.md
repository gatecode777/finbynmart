## Behaviour
- **One canonical filter**: the `status` value drives chips, cards and the Status select; filter, sort and page live in the address (`?status=&q=&range=&dateBasis=&currency=&sort=&page=`), so Back from a detail page returns to the same list. Any change resets to page 1.
- **Search** is sent 300 ms after the last keystroke; a newer request cancels the older one and an overtaken answer never overwrites a newer one. It covers order, quotation and inquiry references and product names; buyer names are not searchable (stated on the page).
- **Date basis** is explicit (Order date / Last updated) whenever a date range is chosen; a custom range needs both dates and says so.
- **Amount sort** needs one currency (amounts in different currencies are never ranked together): with one currency in use it is applied automatically, otherwise the page asks for one.
- **Export** posts the current filters and downloads the CSV (≤ 5,000 rows); the notice states the real row count and when the cap cut the file short.
- **View** opens `/supplier/orders/[reference]`: a compact read-only page (items as stored, order history with the buyer's cancellation reason as plain text, summary with buyer business name / amount / status / fulfilment / payment, links to the company's own quotation and inquiry only, and a "Not available yet" card explaining that confirming, cancelling, updating fulfilment, payments, shipment tracking and invoices do not exist).
- **Not offered, with the reason shown**: Create Order, Confirm, Cancel, Update Fulfilment, Mark Paid.

## States
Loading skeleton (after 250 ms) · filter refresh (`aria-busy`) · **No orders yet** (honest: nothing creates orders yet; no samples) · **No matching orders** with Clear · **No seller linked** · error with an alert and **Try again** (never an empty list shown as success) · permission denied (redirect to `/forbidden?portal=supplier`; API 403) · session expired (sign-in redirect) · payment unavailable (every row, in words) · export unavailable (button hidden when the role cannot export; failure message when it fails).

## Accessibility
Semantic table with caption and column headers; mobile fields are labelled `dl` pairs; statuses are text plus icon; status chips and cards are `aria-pressed` buttons; labelled search and selects; `aria-live` results region; 44 px targets; visible focus; the drawer is a labelled modal; reduced-motion respected (no page animation); print hides the controls on the detail page.
