# Page 35 — Buyer Compare Products

Route (buyer only): `/buyer/compare-products` (the earlier `/buyer/compare` permanently redirects). This extends the page first built as tracker ID 102 (`docs/page-designs/buyer-compare-products.md`); it was modified, not rebuilt. Design reference: the owner's generated Page 35 image (not stored in the repo). Design system: buyer shell with Compare Products current, teal/gold tokens, Anton heading, Montserrat body, shared Modal/ConfirmDialog/Toast, the quotation comparison table styles.

## Deliberate differences from the reference image

The image shows SKUs, supplier logos, "In Stock / On Offer" status, original prices with percentage discounts, fabric specifications for every product, colour swatches, key-feature lists, five-star supplier ratings with counts, lead times and certifications. The catalogue holds none of those, so they are **not drawn**: the column header shows the product's own code instead of a SKU; no logo, stock status, offer, discount, swatch, feature list, lead time or certification appears; rows nobody has data for are not drawn and are listed in a note ("Not available for these products, so not shown: availability, lead time, certifications, warranty"); the Rating row appears only for sample listings that carry a rating. Specifications are whatever the products really state, grouped by their own group, not textile fields forced onto every category.

## Layout

"Compare Products (n)" heading with the PRD description; actions Back to Saved Products, Add More Products (the Product Explorer, disabled with a note at four) and Clear All (confirmed). Chips of the selected products with an accessible Remove. Notes: warnings (different units or currencies, products no longer available) and information (estimated prices, different categories) drawn differently. The comparison card: **Highlight differences** and **Show differences only** controls; the table (from 900 px; a criteria column that stays visible while scrolling, inside a named, keyboard-focusable scroll region) with a header per product (image, name link, product code, supplier with verification, category), sections (Price & order, Product, Supplier, each specification group, Specific to one product), "Differs" words and highlighted cells, a neutral "Lowest listed price" / "Lowest minimum order" tag only when currency and unit match, and an Actions row per product: **Add to Inquiry** (that supplier's inquiry form), **View Product**, **Save Product** (the shared wishlist heart), **Remove**. Below 900 px one card per product with the same sections and actions.

States: one product ("add at least two"), nothing to compare (Browse Products and Open Saved Products), a product no longer available (no link, removable), load error with Try again, removal and clear always asked first and reported only after the server answered. Entry points: the round Compare button on every product card (top-left of the picture), the Compare button on a product page and on saved-product cards.

Accessibility: headings and a table with row and column headers and a caption, difference marks as words, labelled checkboxes, dialogs trap and return focus. Tested at 16 widths. Contrast was not measured with a tool.
