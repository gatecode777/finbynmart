# Buyer Compare Products (`/buyer/compare`, tracker ID 102)

No PRD or reference image was sent; the page reuses the quotation comparison layout (`docs/page-designs/30-buyer-quotation-details-comparison.md`) and the design system in `DESIGN.md`: buyer shell with Compare Products current, breadcrumb Home / Buyer Dashboard / Compare Products, heading "Compare Products", up to four products. Table from 900px (label column + one column per product with image, name link, Remove), one card per product below. Rows: price (estimates labelled), price unit, minimum order, category, subcategory, supplier, location, supplier type, verification, rating, and up to 12 common specifications. "Differs" word on differing rows; "Not Provided" for missing values; notices for mixed units, estimated prices, unavailable products. Actions per product: Get Quote (the supplier's inquiry form), View Product, Remove; header: Add from Saved, Clear all (both removals ask first). No ranking or "best" label. Empty state links to Saved Products and Products.
Entry points: the Compare button on product pages and Saved Products cards (adds or removes; signed-out visitors go to sign in; "View comparison" appears once added). API and rules: `docs/backend/COMPARE_PRODUCTS_AUDIT_AND_API.md`.
