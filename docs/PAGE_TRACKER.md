## Status vocabulary

Table values: **Not Started · Reference Received · In Progress · Complete**.
They map to the three tracks defined in `CLAUDE.md`:

- Design: Not Started → Reference Received → In Progress (spec being written) → Complete (reference finalized, spec written, implementation prompt delivered and approved, consistent with DESIGN.md).
- Prompt: whether the page's implementation prompt has been prepared and delivered.
- Development: Not Started → In Progress (code exists, not verified) → Complete (implemented **and** functionally verified with real data flows).
- QA: Not Started → In Progress → Complete (responsive, accessibility, functional and visual checks all pass).

Nothing is marked Complete because code was generated. A page that exists in code but has no approved design, prompt or QA is **Development: In Progress**.
