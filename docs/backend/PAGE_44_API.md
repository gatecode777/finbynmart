# Page 44 — API contract (supplier quotation versions)

Common: session → `requireSupplierApi()` (401 / 403) → rate limit (reads reserved; **writes exact**: revisions 20 / 10 min, withdraw 20 / 10 min) → service. Every query carries `supplierKey ∈ the session company's sellerKeys`; an unknown, malformed or another supplier's **reference**, and an unknown or foreign **version**, are the **same 404**; a syntactically malformed `?version` (not a whole number 1 … 100,000) is a **400** validation answer from the route before anything is read (it reveals nothing; the page itself answers 404 for it). Writes refuse cross-site requests (403) and bodies over 24 kB (413). Private, `no-store`. Version numbers are whole numbers 1 … 100,000.

| Route | Behaviour |
|---|---|
| `GET /api/supplier/quotations/[reference]?version=n` | the selected version (default: the **current** offer; if none, the highest). `pointers {currentVersion, acceptedVersion, revisionDraft, totalVersions}`, `historical {isHistorical, message, currentHref}`, the stored line / amounts / terms, `financial {source: snapshot / stored / unavailable, integrity {ok, note}, policyVersion, taxRule}`, the first 20 version **summaries** (+ `hasMoreVersions`, `nextVersionCursor`), per-version events, capabilities (`withdraw`, `withdrawVersion`, `editDraft`, `createRevision {available, reason, continueHref}`, `downloadPdf:false`) |
| `GET …/versions?limit=&cursor=` | version summaries newest first (20 / 50 max; `cursor` = lowest version shown, ≥ 2): number, status, current / accepted / draft, dates, total (provisional for a draft), validity, revision reason, author (the company name), link. **No line items, events or snapshot input** |
| `GET …/compare?from=&to=` | differences between two versions of this quotation: `{from, to, comparison {changes[], currencyChanged, identical, commercialChanges, formattingOnly}, notes[]}`. 422 for a missing / non-numeric / equal pair; 404 if either version is not in this quotation and company. Read only |
| `POST …/revisions` `{baseVersion, reason, idempotencyKey}` | creates the revision **draft** (201) or returns the original on a replay (200). 409: `NOT_CURRENT`, `NOT_ALLOWED` (accepted / rejected / withdrawn / draft; the message says why), `REVISION_EXISTS` (+ `editHref`), `INQUIRY_CLOSED`, `IDEMPOTENCY_CONFLICT`. 422 for a reason outside 3–300 characters or a bad key. Sends nothing to the buyer |
| `POST …/withdraw` `{confirm: true, reason?, expectedVersion?}` | withdraws the **current** version while it waits on the buyer. `expectedVersion` ≠ current → 409 `NOT_CURRENT`. One transaction (status + outbox). Answer: the real state and `buyerNotice` (recorded / queued / not recorded because the buyer switched it off) |
| `GET …/activity` | the quotation's real events across versions, newest first, ≤ 50 (`truncated`): draft created, version submitted, revision draft created (with reason), version replaced, withdrawn (reason), the buyer's recorded decisions, derived validity end. No viewed / read / delivered / order / payment |
| Edit / submit a revision | the Page 43 routes (`GET …/draft`, `PATCH …`, `POST …/preview`, `POST …/submit`); a revision draft is found as the highest draft version |

Not created (BLOCKED): `GET …/pdf`, attachment routes.
