## 2. Classification criteria

- **Built**: the intended screen and its essential interactions exist in source with real handlers or data. Backend and runtime readiness are separate columns. A static or draft-copy page is Built when the screen is complete (content approval is reported separately).
- **Partially Built**: a real route exists but a named essential section, action or data relationship is missing.
- **Placeholder**: generic template, "not published", or sample-only. (None remain.)
- **Not Built**: no route and no covering page.
- **Covered**: the purpose is delivered by another real route/tab/workflow, named in the matrix. A redirect alone does not count.
- **Plan Conflict**: none found.
- Where no detailed original specification exists (for example Settings, Reports, Audit Logs) the criterion is: does the page deliver its plain purpose for the role with real data and handlers, without invented capabilities? A prompt, a mockup, a folder or a sidebar link was never counted.
