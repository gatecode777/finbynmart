**Counting rules.** One tracker row = one entry. A row is an alias/duplicate when the tracker or the code shows another entry already provides the same screen (canonical route named); a row is a plan conflict when it is a feature rather than a page or its name cannot be matched to a screen. Neither is counted as a page. Tabs, dialogs and drawers are not pages. A route file alone is never "BUILT": every BUILT page was read down to its component tree and has its planned sections and main controls in code. "Browser verified" appears only where the route was actually opened (see J). Existing pages that are not in the plan (21 routes) are listed in H and are not counted.
